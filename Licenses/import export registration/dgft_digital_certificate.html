OVERVIEW

What is DGFT DSC?

DGFT Digital Signature Certificate is a Class 3 DSC used to access the Directorate General of Foreign Trade (DGFT) portal and complete export-import related activities. It is your digital identity for IEC applications, license filings, incentive claims and other online DGFT transactions.

DSC is issued by Certifying Authorities licensed by the Controller of Certifying Authorities (CCA) under the IT Act, 2000. For DGFT, a Class 3 DSC with organisation details (where applicable) and sign + encrypt capability is required. The private key is stored on a USB token. Video KYC is widely used for identity verification, enabling fast issuance.

TYPES

DSC Classes — What DGFT Accepts

Class Security Typical Use DGFT
Class 1 Basic Email, basic web auth No
Class 2 Medium ITR, MCA, GST (legacy) No
Class 3 High DGFT, e-tender, EPFO Yes
DGFT DSC Highest DGFT portal (sign + encrypt) Yes
Since 2021, new DSCs are Class 3 only. For DGFT you need Class 3 with signing and encryption (combo), not sign-only.

DOCUMENTS

What You Typically Need

1. PAN

PAN of the individual applicant (and entity PAN for organisation DSC).

2. Aadhaar

Aadhaar for address verification and video KYC (webcam required).

3. Photograph

Passport-size photo of the applicant / authorised signatory.

4. Organisation Proof

COI, Partnership Deed or registration proof if DSC is for company/firm use.

5. Authorisation

Board resolution or authorisation letter when applying for organisation DSC.

6. Contact Details

Active email and mobile number linked to the application for OTP and KYC.

PROCESS

How DGFT DSC is Obtained

1. Requirement Check

Confirm Class 3 sign + encrypt, validity (1/2/3 years) and individual vs organisation DSC.

2. Document Submission

Submit PAN, Aadhaar, photo and organisation documents (if any) to the Certifying Authority channel.

3. Video KYC

Complete identity verification via video call (webcam and microphone required).

4. Issuance & Token

Certificate is generated and loaded on USB token; token shipped or collected as arranged.

5. Installation Support

Install token drivers and register DSC on DGFT (and other portals) with PIN setup.
